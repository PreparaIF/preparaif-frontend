# PreparaIF

O **PREPARAIF - PLATAFORMA PARA APRESENTAÇÃO DOS CURSOS DO INSTITUTO E ACOMPANHAMENTO DO PROCESSO DE SELEÇÃO PELOS CANDIDATOS** é um projeto de pesquisa que tem como objetivo desenvolver um **site educativo** voltado para estudantes que desejam se preparar para processos seletivos do **Instituto Federal de Alagoas**.  
A plataforma oferecerá conteúdos, simulados e ferramentas interativas que auxiliam o aprendizado e o acompanhamento do progresso dos usuários.

---

## Objetivo do Projeto

Criar uma solução digital acessível e intuitiva que facilite o estudo dos alunos interessados em ingressar no Instituto Federal, promovendo autonomia e engajamento no processo de aprendizagem.

---

## Motivação

Muitos estudantes enfrentam dificuldades para encontrar **materiais confiáveis e organizados** sobre os conteúdos cobrados nos exames de ingresso do IF.  
O **PreparaIF** surge como uma alternativa gratuita, centralizando informações, recursos de estudo e simulados, em uma interface moderna e amigável.

---

## Tecnologias Utilizadas

O projeto está sendo desenvolvido com as seguintes tecnologias:

- **Frontend:** Next.js / React  
- **Estilização:** Tailwind CSS  
- **Backend:** Node.js  
- **Banco de Dados:** PostgreSQL  
- **Versionamento:** Git e GitHub  

> *Essas tecnologias podem ser atualizadas conforme o avanço do projeto.*
